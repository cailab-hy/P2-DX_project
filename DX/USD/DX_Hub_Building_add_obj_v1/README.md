# DX Hub Building + objects v1 (케어룸 침실 + 주방 + 중앙 홀)

빈 건물 `../DX_Hub_Building_no_obj_v1/`(2026-10-16 이전 이름 `DX_Hub_Building_v3`)에 케어룸(침실 공간), 주방, 중앙 홀 가구와 안내데스크 벽 로고를 배치한 버전입니다.
빈 건물 파일은 수정하지 않고 참조만 하므로, 빈 건물을 다시 생성하면 이 장면에도 자동으로 반영됩니다. 건물 수정(카운터 타공, 냉장고 틈새, 로고)은 이 폴더의 파일에만 덮어쓰기로 들어 있습니다.

## 공간별 USD (홀 · 주방 · 침실, 2026-10-16)

전체 파일(`DX_Hub_Building_add_obj_v1.usda`)은 그대로 두고, 공간별 파일 세 개를 따로 둡니다.

| 파일 | 공간 | 남기는 가구 그룹 | 영역 박스 [x0, x1, y0, y1] (m) | 남는 건물 프림 |
|---|---|---|---|---|
| `DX_Hub_Building_add_obj_v1_Hall.usda` | 홀 | `Furniture/Hall` | [−13.5, −4.2, −4.05, 21.75] + [−4.2, 3.85, −4.05, 16.25] | 935 / 1402 |
| `DX_Hub_Building_add_obj_v1_Kitchen.usda` | 주방 | `Furniture/Kitchen` | [−2.0, 3.85, 2.3, 16.25] | 288 / 1402 |
| `DX_Hub_Building_add_obj_v1_CareRoom.usda` | 침실 | `Furniture/CareRoom` | [−4.45, 3.85, 16.15, 21.75] | 136 / 1402 |

각 파일에는 `_scene.usda`(PhysicsScene, GPU dynamics 포함)가 하나씩 짝으로 있어 Isaac Sim에서 바로 열 수 있습니다.

**전체 파일과 같이 업데이트되는 원리**

- **참조:** 공간 파일은 전체 파일을 그대로 **참조(reference)**하고, 그 위에 `active = false` 덮어쓰기만 들어 있습니다. 형상, 재질, 물성, 가구 위치, 건물 수정은 모두 전체 파일에서 오므로, 전체 파일을 고치면 세 공간에 바로 반영됩니다. 다시 생성할 필요도 없습니다.
- **가구:** 가구는 **공간 그룹 단위**로 끕니다. 예를 들어 침실 파일은 `/Furniture/Hall`과 `/Furniture/Kitchen` 그룹을 통째로 끕니다. 그래서 전체 파일의 `/Furniture/CareRoom`에 가구를 새로 추가하면 침실 파일에만 자동으로 나타납니다(`--sync-test`로 확인).
- **건물:** 벽, 창, 유리, 기둥, 천장 구역, 충돌체, 조명 같은 건물 부분은 영역 박스(+0.2 m 여유)와 겹치는 것만 남깁니다. 바닥 충돌판, 여러 공간에 걸친 큰 천장 메시, 하늘 조명은 항상 남습니다.
- **목록 재생성:** 건물 목록은 `21_add_obj_assemble.py`를 실행할 때마다 끝에서 `27_split_rooms_add_obj.py`가 자동으로 다시 만듭니다. 건물을 바꾸거나 영역 박스(`config` → `rooms`)를 바꾼 뒤 `python 27_split_rooms_add_obj.py`만 따로 실행해도 됩니다.
- **주의:** 공간 파일은 스크립트가 만든 파일이므로 직접 고치지 마세요. 공간별로 다른 것을 넣고 싶으면 전체 파일의 해당 공간 그룹에 넣으면 됩니다.

room = AssetBaseCfg(prim_path="/World/DX_Hub_Building_add_obj",

- 화분 잎은 충돌이 없습니다.
- 주방: 바스툴, 쇼케이스, 정수기, 냉장고, 전자레인지의 세부 형태와 색은 판매 페이지 치수와 사진을 보고 만든 값입니다. 쇼케이스 판매 페이지(newbis)는 접속이 막혀(403) 알려주신 치수를 썼습니다.
- 주방 화분은 요청대로 침실과 같은 USD입니다. 실물은 키가 큰 원형 화분이라 모양이 다릅니다.
- 소화기 크기는 표준형 값입니다. 스캔에는 소화기로 확정할 만한 물체가 없어 후보 원통들의 높이만 참고했습니다.
- 전자레인지 걸쇠는 물리가 아니라 컨트롤러 규칙입니다(위 예시).
- 홀: TV 거치대와 창가 책상·사무용 의자의 크기와 모양은 사진에서 어림잡은 값입니다. 창가 책상의 위치는 알려주신 배치도를 서쪽 창 기준으로 놓아 정했고(6월 스캔 당시와 배치가 다름), 줄 간격은 의자를 뺄 공간(약 0.6 m)을 기준으로 잡았습니다.
- 홀 소파 묶음과 긴 책상의 위치는 6월 스캔 위치입니다. 사진상 그 뒤로 바뀌었다면 알려주세요.
- 커피 로봇: 판매 페이지의 무게 21 kg, 가반하중 380 kg은 서로 뒤바뀐 것으로 보입니다(A0509 자체가 약 21 kg, 가반하중 5 kg). 부스는 크기만 썼습니다. 내부 배치(머신, 디스펜서, 픽업대)와 색, 키오스크 크기는 사진과 영상에서 추정했습니다.
- A0509 원본 `a0509.usd`는 `metersPerUnit`가 0.01로 적혀 있지만 값은 m 단위입니다. Isaac Sim이 단위를 자동 보정하면 100배 작아지므로, 메타데이터만 1.0으로 고친 `a0509_meters.usd`를 참조합니다. 원본과 라이선스 파일도 함께 두었습니다.
- 반팔티는 절차적으로 만든 메시라 목 둘레 리브, 봉제선 두께, 앞뒤 목 깊이 차이가 없습니다. 접기 과제의 키포인트가 필요하면 정점 번호(customData.mesh)를 기준으로 고르면 됩니다.
- 싱크 볼 바닥 충돌체는 터널링을 막기 위해 보이는 바닥보다 두껍게(3 cm) 만들었습니다.
